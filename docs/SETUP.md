# Q10UX SpiderAutoPack v2

Includes Home (index), About, and Case Studies scraping into MDX.

## Usage
```bash
unzip -o Q10UX_SpiderAutoPack_v2.zip -d .
node scripts/apply-package-scripts.mjs
npm run autoimport
npm run dev
```

- Home index.mdx only generated if missing
- About and case studies refreshed every run
